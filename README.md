# DSA : data structure and Algorithms.
-> A Data Structure is a way of organizing, storing, and managing data in a computer so that we can access, modify, and process it efficiently.
Real-world example:
Imagine a college classroom. There are 50 students, and each student has:
- USN number
- Name
- Marks
- Department
-> We need to organize and store this information properly. Data structures help us do that.
Types of Data Structures
1. Array :
-> Stores multiple elements of the same type in continuous memory locations.
    Example: int marks[5] = {80, 90, 75, 85, 95};
2. Linked List :
-> Stores data in nodes connected using pointers.
3. Stack :
-> Follows LIFO (Last In, First Out).
    Example: A stack of plates.
4. Queue :
-> Follows FIFO (First In, First Out).
    Example: People waiting in a ticket queue.
5. Tree : 
-> Organizes data in a hierarchical structure.
    Example: Computer folder structure.
6. Graph :
-> Represents connections between different objects.
    Example: Google Maps locations and roads.
# Algorithm :
-> An Algorithm is a finite set of step-by-step instructions used to solve a particular problem or perform a specific task.
Real-world example: Making tea
1. Take water.
2. Boil the water.
3. Add tea powder.
4. Add milk and sugar.
5. Boil for a few minutes.
6. Filter and serve.
-> These step-by-step instructions are an algorithm.
Example: Algorithm to find the largest number
-> Suppose we have three numbers:
10, 25, 15
Steps:
1. Start.
2. Read three numbers A, B and C.
3. Compare A, B and C.
4. Find the largest number.
5. Display the result.
6. Stop.
Output: 25
